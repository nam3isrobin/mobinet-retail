# Mobinet Retail · Scrollcraft Landing Page

A premium scroll-driven interactive landing page for **Mobinet Retail**. Built on the Scrollcraft engine using the **Continuous World** grammar with **worldflight mode**.

## Live Deployment
- **Vercel**: [mobinet-retail.vercel.app](https://mobinet-retail.vercel.app)

## Architecture
- **Grammar**: Continuous World (`worldflight`)
- **World**: Nocturne-showroom (35mm anamorphic, deep charcoal, steel blue, amber accents)
- **Signature Move**: Haptic Cursor Field (physics-driven proximity tilt + luminance bloom)
- **Typography**: Google Fonts `Outfit` (Headings) & `Geist` (Body)
- **Assets**: 6 cinematic showroom worldflight legs with poster webp frames

## Stack
- Vanilla HTML5 / Modern CSS Custom Properties
- `scrollcraft.js` & `scrollcraft.css`
- Zero external build step required (Static DOM)
